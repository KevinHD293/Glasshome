# Glass Home Performance v1

Based on Options v5.1. Added focus speed settings (0, 110, 180, 260 ms) in TV Options and phone UI. Default 110 ms. Uses critically damped focus springs; times are approximate visual settling targets, not guaranteed exact durations. Other animation springs are unchanged. Existing settings persist.

Build with the existing GitHub Actions workflow. Test rapid D-pad input, Options navigation, web sync, and restoring defaults.
